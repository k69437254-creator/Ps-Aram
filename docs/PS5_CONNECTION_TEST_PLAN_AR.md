# خطة قبول اتصال PS5 — PS Link

لا يُعلن أن الاتصال جاهز للإنتاج قبل اجتياز الاختبارات التالية على هاتف Android وجهاز PS5 حقيقيين.

## بوابة البناء

- [ ] `bash scripts/bootstrap.sh` يجلب commit Chiaki-NG المثبت دون أخطاء.
- [ ] `bash scripts/check-source.sh` ينجح.
- [ ] `:core:shared:testDebugUnitTest` ينجح.
- [ ] `:mobile:assembleDebug` ينجح.
- [ ] `:tv:app:assembleDebug` ينجح (اختبار تطبيق التلفاز منفصل عن اتصال PS5).
- [ ] APK الهاتف يحمل `applicationId=com.pslink.app`.
- [ ] APK التلفاز يحمل `applicationId=com.pslink.tv`.

## اختبار PS5 داخل المنزل

- [ ] PS5 يظهر في قائمة الاكتشاف التلقائي.
- [ ] عند عدم ظهوره، ينجح التسجيل اليدوي بواسطة عنوان IP.
- [ ] التسجيل ينجح باستخدام PSN Account-ID صحيح بصيغة Base64 ورمز Link Device حديث من 8 أرقام.
- [ ] يظهر PS5 بعد التسجيل كجهاز مسجّل بعد إغلاق التطبيق وإعادة فتحه.
- [ ] الاتصال ينشئ بثًا حيًا للصورة والصوت لمدة 15 دقيقة على الأقل.
- [ ] أزرار اللمس تحرك شخصية اللعبة وتنفذ الأوامر الأساسية.
- [ ] وحدة تحكم Bluetooth تعمل في الاتجاهات والأزرار والعصوين والمحفزين.
- [ ] قطع Wi-Fi وإعادته ينتج رسالة حالة مفهومة ويمكن إعادة الاتصال.
- [ ] وضع PS5 في Rest Mode ثم إيقاظه من الهاتف ينجح إذا كانت إعدادات Rest Mode مفعّلة.

## اختبار الأداء والاستقرار

- [ ] تسجيل دقة البث ومعدل الإطارات الفعليين.
- [ ] قياس متوسط وزمن الاستجابة الطرفي وليس الاعتماد على رقم نظري.
- [ ] مراقبة RAM والحرارة واستهلاك البطارية خلال جلسة 30 دقيقة.
- [ ] اختبار 720p/30 ثم 720p/60 قبل رفع الدقة.
- [ ] اختبار الرجوع إلى الشاشة الرئيسية وإعادة الاتصال دون انهيار التطبيق.

## قرار النشر

- **جاهز لاختبار داخلي:** جميع بوابة البناء ناجحة وبدأ البث على PS5 واحد على الأقل.
- **جاهز لإصدار تجريبي واسع:** اختبارات التحكم والاستقرار وإعادة الاتصال ناجحة على أكثر من هاتف وشبكة.
- **جاهز للإنتاج:** مراجعة التراخيص والأمان وتوقيع Release وسياسة الدعم والخصوصية، إضافة إلى نجاح مجموعة اختبارات الأجهزة.

لا تحوّل خانة غير مختبرة إلى «ناجحة» لمجرد أن البناء نجح.
