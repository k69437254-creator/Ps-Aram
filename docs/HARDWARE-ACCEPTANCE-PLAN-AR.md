# خطة قبول الأجهزة الفعلية لـ PS Link

لا تثبت اختبارات المصدر أو محاكاة البروتوكول أن فك الترميز أو التقاط صوت PS5 يعمل على أجهزة فعلية. سجّل لكل اختبار إصدار النظام وطراز الجهاز وإصدار التطبيق وتاريخ التنفيذ ورابط CI والنتيجة.

| المسار | الاختبار المطلوب | دليل القبول |
|---|---|---|
| PS5 → Chiaki → Android phone | جلسة Remote Play طويلة، تغيير جودة الشبكة، إعادة الاتصال | فيديو مستمر وسجلات خالية من تسرب بيانات الاقتران |
| Chiaki PCM → AAC → HLS | صوت فعلي متصل دون Playback Capture، ثم اختبار fallback | وجود AAC حقيقي قابل للفك، وعدم ازدواج الصوت |
| HLS → Roku | WSS/HTTPS مع سلسلة شهادة موثوقة، تشغيل/إيقاف/إعادة اقتران | فيديو وصوت وترجمة، رفض شهادة خاطئة |
| HLS → Tizen/webOS | تشغيل متواصل وتبديل الشبكة | HLS playback وصوت دون توقف غير متوقع |
| HLS → Web/Xbox Edge | متصفحات مدعومة، TLS، انتهاء صلاحية الجلسة | تشغيل متوافق مع صلاحيات المتصفح |
| Android TV direct | PCM وفيديو Chiaki عبر المسار الحالي | مزامنة مستقرة عبر جلسة طويلة |
| OCR عربي/لاتيني/ياباني/صيني/كوري | مجموعة لقطات ألعاب حقيقية متنوعة، بما فيها حوار قصير | CER/WER أو مقاييس دقة، زمن التقاط/ترجمة، معدل تفويت الحوار |
| Long-run A/V | تشغيل 30 و60 دقيقة على الأقل لكل عائلة جهاز | قياس الانحراف الصوتي/المرئي بمرور الزمن وليس انطباعًا بصريًا فقط |

لا تضع علامة Pass دون ملفات تسجيل أو عينات اختبار ومقاييس قابلة للمراجعة. Xbox Edge في النطاق الحالي يعني متصفح Edge، وليس تطبيق Xbox أصليًا.
